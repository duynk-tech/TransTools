# Trans Tools v1.4.2

- Hỗ trợ chính thức nền tảng Windows (.NET 9 WPF): Cung cấp bộ cài đặt TransTools-Setup.exe và bản di động TransTools.exe.
- Hỗ trợ thu âm và dịch âm thanh hệ thống loopback qua WASAPI trên Windows.
- Nhận diện giọng nói STT offline với mô hình Whisper.
- Hỗ trợ dịch đa mô hình AI (OpenAI, Gemini, Claude, Groq, DeepSeek, Ollama) và Google Dịch.
- Trợ lý mascot Chip Chip nổi trên màn hình và cửa sổ phụ đề nổi thời gian thực trên Windows.
- Đồng bộ phát hành đồng thời trên cả hai hệ điều hành macOS và Windows.
