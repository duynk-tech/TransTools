# Website giới thiệu TransTools

Trang GitHub Pages nằm tại `docs/index.html`, CSS tại `docs/site.css`, tương tác tại `docs/site.js`. Không cần CDN, framework hay bước build.

Ảnh mới chụp trực tiếp từ app ngày 02/10/2026: dashboard, quick-translate, notebook, vocabulary, flashcard. Sổ tay đang hiển thị bản ghi nghe nội dung Spotlight. Ảnh cài đặt đã chụp nhưng không dùng trên trang do popover bị cắt ở cạnh cửa sổ. Không chụp hoặc hiển thị API key.

Chip Chip trên website dùng bộ PNG hiện hành của app (front, coffee, writing, flowers, sleeping); đây là minh họa bằng tài nguyên thật, không phải ảnh chụp cửa sổ mascot. Bầu trời tương tác là minh họa web; app tự đổi theo giờ trên máy. Chỉ cắt lề trong suốt của bản sao PNG trong docs, không sửa Resources.

Đã kiểm tra trên browser: tab tính năng, phóng to/đóng ảnh, đổi bầu trời và mascot. Ở viewport 390×844 không tràn ngang, ảnh tải thành công. Link tải giữ GitHub Releases. Chưa publish/push thay đổi lên GitHub Pages.

Preview: `python3 -m http.server 8765 --bind 127.0.0.1 --directory docs`.
